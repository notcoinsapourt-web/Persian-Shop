# Persian Shop Frontend

Premium digital products marketplace frontend.

Stack:
- Next.js
- TypeScript
- Tailwind CSS
- RTL Support
- Vazirmatn / Inter typography
- Framer Motion

Core modules:
- Homepage
- Categories
- Products
- Product Detail
- Cart
- Checkout
- User Dashboard

Development order:
